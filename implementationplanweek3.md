# SecondSelf Week 3: The Cartographer (Visualizing the Brain)

This plan covers Week 3 of SecondSelf. The objective is to take the interconnected Markdown files sitting in our `wiki/` directory and turn them into a live, interactive 2D graph so you can physically see the relationships between your ideas.

## User Review Required

> [!IMPORTANT]
> - **Visualization Library Choice**: We need to select a JavaScript graph rendering library for the frontend. I propose using **Vis.js** (specifically `vis-network`). It provides excellent physics-based node interactions out of the box and is very easy to embed.
> - **Delivery Method**: I propose generating a static HTML file (`index.html`) that you can simply double-click to open in your browser, meaning you won't need to run a complex web server just to view your brain.

## Proposed Changes

---
### The Graph Builder (Week 3)

#### [NEW] build_graph.py
- Parses every `.md` file inside the `wiki/` directory.
- Extracts the Node ID, Title, PARA Category, and Tags by reading the YAML frontmatter.
- Uses Regex to find all `[[Semantic Links]]` at the bottom of the markdown to establish the connections (edges).
- Exports this data as a structured JSON object containing `nodes` and `edges`.

#### [NEW] index.html (The Viewer)
- A sleek, dark-mode HTML page.
- Imports the `vis-network` JavaScript library via a CDN.
- Ingests the JSON graph data generated by `build_graph.py`.
- Renders an interactive physics-based network graph where users can drag nodes, zoom, and pan.

#### [MODIFY] requirements.txt
- No heavy backend dependencies are strictly needed for this phase since it's mostly JSON parsing and frontend rendering, but we will ensure our environment is clean.
